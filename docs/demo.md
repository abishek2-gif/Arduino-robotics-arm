## Suggested 45–60 second sequence
1. Show the complete arm and identify the Uno, four servos and external power supply.
2. Demonstrate each joystick axis separately.
3. Show controlled combined motion without payload.
4. Pick and release a light object only after successful testing.
5. Show the repository and briefly describe the next upgrade.

Record servo models, payload mass and firmware commit in the video description. Avoid calling joystick operation autonomous or camera-controlled.
